# 爱拼豆 APK

## 安装包

- `AiPindou-v3.4.0.apk`
- 支持 Android 8.0（API 26）及以上版本。
- 应用完全离线运行，不申请网络权限或存储权限。

## Android 适配

- 启动时自动恢复最近编辑，不再因重新打开应用而丢失图纸。
- 项目直接保存在应用内项目库，保存和打开项目不跳转系统文件管理器。
- PNG 直接保存到系统相册的“爱拼豆”目录。
- 外部图片和 `.pbdproj` 文件仍可通过可选导入入口打开。
- 竖屏改为画布优先工作台：单行无框顶栏、常驻画布与收起/半屏/展开三段参数面板，并可停留在任意拖动高度。
- 竖屏顶栏直接提供撤销、恢复、历史、智能拼豆板和更多；参数面板除三个标准档位外也支持任意高度停靠。
- “基础 / 色彩 / 精修 / 导出”合并在参数面板头部；切换分类会保留当前面板高度，生成后可按设置自动收起。
- 横屏在手机和平板上统一使用左侧支持面板与右侧画布，并直接显示完整项目操作。
- 顶栏标题可直接重命名；竖屏仅保留撤销、恢复、智能拼豆板和更多。
- “更多”使用右上角锚定菜单，收纳保存、项目库、历史、新建、空白图纸和设置。
- 预览工具改为右侧窄工具轨，支持图纸/原图、缩小、放大、适应和双击适应。
- 去背景移入基础参数，继续使用离线边缘连通背景识别算法。
- 智能拼豆板与高级裁剪统一为专注工作区；竖屏使用同款三段面板，横屏使用左右支持面板。
- 智能拼豆板按板型、布局、分板、颜色组织；锁定后仍可使用分板、颜色和显示效果。
- 高级裁剪按裁剪、位置、识别、预览组织；有效预览生成前确认按钮不可用，取消会恢复完整快照。
- 全应用采用暖米白、墨色和玉绿色“纸本工坊”视觉，取消紫色、渐变、玻璃模糊和嵌套卡片。
- 外观可跟随系统，也可在设置中固定为浅色或深色；深色模式使用暖炭黑、暖灰与低饱和玉绿。
- 精修重新分为“统一换色”和“绘制”两个展开工具；绘制支持按拼豆色号直接加入已选颜色，并提供就近撤销与恢复。
- 新建空白图纸后会直接进入精修、展开绘制工具并开启点选模式。
- 识别、导出尺寸、标签方向、主题等选项统一改为行内展开式选择，不再弹出系统下拉菜单。
- 图纸右侧的生成预览、一键镜像和导出 PNG 独立成第二组快捷工具轨。
- APK 网页资源固定写入 `assets/index-pro.html`，与 WebView 的离线加载地址保持一致。
- 按钮加入即时按压反馈、键盘焦点环和精细化悬停反馈，并完整遵循减少动态效果设置。
- 加大触屏按钮与颜色卡片，适配安全区域。
- 编辑预览时支持手指点按、连续拖动绘制和连续擦除。
- 创作设置统一为“基础 / 色彩 / 精修 / 导出”。
- 默认直接使用完整高级功能，不再显示普通/高级模式切换和品牌横幅。
- 图纸预览恢复为稳定的 Canvas 图纸样式，支持按钮缩放、双指缩放、单指拖动和自动适应屏幕。
- Canvas 使用更高的内部绘制分辨率，放大查看文字、格线和颜色块时更加清晰。
- 放大后的预览可横向或纵向拖动，“项目与步骤”入口已移动到顶部撤销/恢复旁边。
- 精准填色时单指负责绘制或擦除，双指可随时拖动画布和捏合缩放，并避免切换手势时误填格子。
- “生成预览 / 一键镜像 / 导出 PNG”集中在图纸右侧的独立快捷工具轨，状态与参数面板保持同步。
- 预览最小可缩放至 5%，PNG 导出分辨率最高支持 16K。
- 基础栏和空白图纸窗口新增 26×26、52×52、104×104、208×208 拼豆板快捷尺寸。
- 空白图纸与导入图片默认使用 52×52，导入或切换拼豆板时不自动勾选按图片比例调整高度。
- 裁剪选框使用更大的圆形缩放手柄和触屏命中区域，拖动时保留手指与手柄的相对位置。
- 应用内确认和错误提示不再使用带 `file://` 标题的网页原生弹窗。
- 镜像会同步处理空白图纸、手绘格子和颜色覆盖记录。
- 应用图标使用透明背景。
- 预览、缩放、拖动和手绘点选统一使用 Canvas，不再依赖 Android WebView 的 SVG 支持。
- 基础设置提供标准图纸、卡通形象、照片原图三种离线识别算法，算法菜单可再次点击收起。
- 普通裁剪支持双指缩放和鼠标滚轮缩放；高级裁剪提供 5×5 红色分区线及独立的整体视图缩放、横移和纵移控制。
- 高级裁剪提供底图位置和缩放微调键；T1 保留为推荐色，但默认不会自动选用。
- 图纸预览可切换到网格对齐的对应原图，并可在该状态下继续精修。
- 智能拼豆板锁定按钮改为不可选择的矢量图标，长按解锁时不再触发系统文字选择。

## 从 0 编辑图纸

点击顶部“空白图纸”，设置标题、宽度和高度后创建。应用会进入高级模式并开启绘制，可使用：

- 画笔
- 橡皮
- 整图填色
- 清空图纸
- 撤销与恢复
- 保存/打开可继续编辑的 `.pbdproj` 项目
- 导出 2K、4K 或 8K PNG
